import { Aside, Steps, Tabs, TabItem } from '@astrojs/starlight/components';

You'll build an app that collects **steps**, **battery level** and **when the app is
opened or closed**, and shows each measurement as it arrives. Once Flutter is set up,
it takes about 15 minutes.
Data stays on the phone for now; [choosing where data goes](/start/where-data-goes/)
comes next.

## Before you start

You need:

- A computer with **Flutter** installed. Follow Google's guide for your system:
  [Install Flutter](https://docs.flutter.dev/get-started/install). When
  `flutter doctor` shows green checkmarks for Android or iOS, you're ready.
- A phone set up for development:
  [Android: turn on USB debugging](https://developer.android.com/studio/debug/dev-options),
  or [iPhone: set up Xcode and your device](https://docs.flutter.dev/get-started/install/macos/mobile-ios)
  (iPhone apps can only be built on a Mac).

The commands below are typed in a **terminal** (Terminal on Mac, PowerShell on Windows).

<Aside type="tip">
Use a **real phone** if you can. Simulators don't have step counters or real
batteries, so they produce very little data.
</Aside>

## Build it

<Steps>

1. **Create an empty Flutter app.** In a terminal:

   ```bash
   flutter create my_first_carp_app
   cd my_first_carp_app
   ```

2. **Add the CARP packages.** This downloads them from pub.dev and adds them to
   your `pubspec.yaml`:

   ```bash
   flutter pub add carp_core carp_mobile_sensing
   ```

3. **Make two small platform changes.** CARP uses phone features that need a
   little setup.

   <Tabs>
   <TabItem label="Android">

   Open `android/app/src/main/AndroidManifest.xml` and add this line just above
   `<application`, so the app may count steps:

   ```xml title="android/app/src/main/AndroidManifest.xml"
   <uses-permission android:name="android.permission.ACTIVITY_RECOGNITION"/>
   ```

   Then open `android/app/build.gradle.kts` and add the two marked parts:

   ```kotlin title="android/app/build.gradle.kts" ins={3,9-11}
   android {
       compileOptions {
           isCoreLibraryDesugaringEnabled = true
           // ...leave the existing lines as they are
       }
       // ...
   }

   dependencies {
       coreLibraryDesugaring("com.android.tools:desugar_jdk_libs:2.1.4")
   }
   ```

   </TabItem>
   <TabItem label="iPhone">

   CARP needs iOS 15 or newer. Open `ios/Runner.xcworkspace` in Xcode, select
   **Runner → General**, and set **Minimum Deployments** to **15.0**.

   Then, so the phone may count steps, add this to `ios/Runner/Info.plist`
   inside the `<dict>`:

   ```xml title="ios/Runner/Info.plist"
   <key>NSMotionUsageDescription</key>
   <string>This app counts your steps for a research study.</string>
   ```

   </TabItem>
   </Tabs>

4. **Replace the app code.** Open `lib/main.dart`, delete everything, and paste:

   ```dart title="lib/main.dart"
   import 'package:flutter/material.dart';
   import 'package:carp_core/carp_core.dart';
   import 'package:carp_mobile_sensing/carp_mobile_sensing.dart';

   void main() => runApp(const MaterialApp(home: StepsPage()));

   class StepsPage extends StatefulWidget {
     const StepsPage({super.key});

     @override
     State<StepsPage> createState() => _StepsPageState();
   }

   class _StepsPageState extends State<StepsPage> {
     final List<String> _log = [];

     @override
     void initState() {
       super.initState();
       _startSensing();
     }

     Future<void> _startSensing() async {
       // 1. The study protocol: WHAT to collect.
       final protocol = SmartphoneStudyProtocol.local(
         name: 'My first study',
         measures: [
           Measure(type: SensorSamplingPackage.STEP_EVENT),
           Measure(type: DeviceSamplingPackage.APP_LIFECYCLE_EVENT),
           Measure(type: DeviceSamplingPackage.BATTERY_STATE),
         ],
       );

       // 2. The client: the engine that runs studies on this phone.
       final client = SmartPhoneClientManager();
       await client.configure();

       // 3. Add the study, deploy it and start collecting.
       final study = await client.addStudyFromProtocol(protocol);
       await client.tryDeployment(study.studyDeploymentId, study.deviceRoleName);
       client.resume();

       // 4. Every piece of data arrives here as a "measurement".
       client.measurements.listen((measurement) {
         setState(() => _log.insert(0, measurement.data.dataType.name));
       });
     }

     @override
     Widget build(BuildContext context) => Scaffold(
       appBar: AppBar(title: const Text('My first CARP app')),
       body: ListView(children: [for (final line in _log) ListTile(title: Text(line))]),
     );
   }
   ```

5. **Run it.** Connect your phone with a cable and run:

   ```bash
   flutter run
   ```

   The app asks for a few permissions (notifications, physical activity).
   Tap **Allow**. Walk around, switch to another app and back, and watch
   `stepevent`, `applifecycleevent` and `batterystate` appear in the list.

</Steps>

## What just happened?

The four numbered comments in the code are the whole of CARP:

| Step in the code | What it means |
| --- | --- |
| **1. Protocol** | The recipe. `.local(...)` is a shortcut for "only this phone, one participant, save data on the phone". |
| **2. Client** | `SmartPhoneClientManager` is the CARP engine. `configure()` starts it with sensible defaults. |
| **3. Add, deploy, resume** | Hands the recipe to the engine, prepares the sensors, and presses *play*. |
| **4. Measurements** | A live stream of everything collected. You can show it, save it, or send it anywhere. |

Every measurement is also saved in a small database on the phone. Nothing leaves the
device. To choose a different place for the data, see
[Where should the data go?](/start/where-data-goes/).

## Want more kinds of data?

Add a **sampling package**. For example, for location and activity (walking, cycling…):

```bash
flutter pub add carp_context_package
```

```dart
import 'package:carp_context_package/carp_context_package.dart';

// At the top of _startSensing(), before creating the protocol:
SamplingPackageRegistry().register(ContextSamplingPackage());

// ...then add measures like:
Measure(type: ContextSamplingPackage.LOCATION),
Measure(type: ContextSamplingPackage.ACTIVITY),
```

The [Measure Types](/carp-mobile-sensing/sampling-packages/available-packages) page lists everything
available, and the [API Reference](/api-reference/) lists all packages.

<Aside>
Each package may need its own permissions (for example location). Its page on
pub.dev tells you which lines to add for Android and iPhone.
</Aside>
