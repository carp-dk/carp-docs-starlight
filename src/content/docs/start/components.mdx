Where each piece lives and what it builds on. Packages are on
[pub.dev/publishers/carp.dk](https://pub.dev/publishers/carp.dk/packages).

## Core

| Component | What it does | Repo | Depends on |
| --- | --- | --- | --- |
| `carp_serializable` | Polymorphic JSON serialization | [carp.sensing-flutter](https://github.com/carp-dk/carp.sensing-flutter) | – |
| `carp_core` | Dart domain model: protocols, deployments, data | [carp.sensing-flutter](https://github.com/carp-dk/carp.sensing-flutter) | `carp_serializable` |
| `carp.core-kotlin` | Kotlin domain model, used by the server | [carp.core-kotlin](https://github.com/carp-dk/carp.core-kotlin) | – |

## Phone framework

| Component | What it does | Repo | Depends on |
| --- | --- | --- | --- |
| [`carp_mobile_sensing`](/carp-mobile-sensing/) | Runs studies on the phone (CAMS) | [carp.sensing-flutter](https://github.com/carp-dk/carp.sensing-flutter) | `carp_core` |

## Sampling packages

All depend on `carp_mobile_sensing`.

| Package | Collects | Also uses |
| --- | --- | --- |
| [`carp_health_package`](/sampling-packages/health/) | Apple Health / Health Connect | [`health`](/plugins/health/) |
| `carp_survey_package` | Surveys and cognitive tests | `research_package`, `cognition_package` |
| `carp_context_package` | Location, activity, weather, air quality | – |
| `carp_audio_package` | Audio and noise | – |
| `carp_connectivity_package` | Bluetooth, Wi-Fi, connectivity | – |
| `carp_communication_package` | Phone calls and SMS | – |
| `carp_apps_package` | Installed apps and app usage | – |

## Backends

| Component | What it does | Repo | Depends on |
| --- | --- | --- | --- |
| CAWS server | Stores protocols, deployments and data (REST API) | [carp-webservices-spring](https://github.com/carp-dk/carp-webservices-spring) | `carp.core-kotlin` |
| `carp_webservices` | Dart client for CAWS | [carp.sensing-flutter](https://github.com/carp-dk/carp.sensing-flutter) | `carp_mobile_sensing` |
| `carp_backend` | Uploads phone data to CAWS | [carp.sensing-flutter](https://github.com/carp-dk/carp.sensing-flutter) | `carp_webservices` |
| `carp_firebase_backend` | Uploads phone data to Firebase | [carp.sensing-flutter](https://github.com/carp-dk/carp.sensing-flutter) | `carp_mobile_sensing` |
