This is the simplest option: **no server, no accounts, no internet**. Measurements
are saved in the app's private storage on the phone.

## It's one setting: the data endpoint

Where data goes is decided by a single setting in the study protocol, the
**data endpoint**. Local storage, CAWS and your own server differ only in this
setting. The rest of the protocol (what to collect, and when) stays the same.

For local storage, pick one of two endpoints:

| Endpoint | Saves data as | Good for |
| --- | --- | --- |
| `SQLiteDataEndPoint()` | A small database on the phone | Apps that show the data back, e.g. "your steps this week" |
| `FileDataEndPoint()` | Text files (JSON), zipped | Handing the data to a researcher |

## Setting up the protocol

Start from [your first app](/start/first-app/) and change the imports at the top of
`lib/main.dart` to this. (`Smartphone` exists in both packages; `hide` tells Dart
to use the one from `carp_mobile_sensing`.)

```dart
import 'package:carp_core/carp_core.dart' hide Smartphone;
import 'package:carp_mobile_sensing/carp_mobile_sensing.dart';
```

Then, in `_startSensing()`, replace the protocol with the steps below.

<Steps>

1. **Create the protocol and choose the endpoint.** This is the one line that
   decides where data goes:

   <Tabs>
   <TabItem label="Database">

   ```dart
   final protocol = SmartphoneStudyProtocol(
     name: 'My first study',
     dataEndPoint: SQLiteDataEndPoint(),
   );
   ```

   </TabItem>
   <TabItem label="Files">

   ```dart
   final protocol = SmartphoneStudyProtocol(
     name: 'My first study',
     dataEndPoint: FileDataEndPoint(),
   );
   ```

   </TabItem>
   </Tabs>

2. **Add the phone and the participant.** The phone is the device that collects the
   data. The participant is the person using it.

   ```dart
   final phone = Smartphone();
   protocol.addPrimaryDevice(phone);
   protocol.addParticipantRole(ParticipantRole('Participant'));
   ```

3. **Say what to collect, and when.** `ImmediateTrigger` means "start right away";
   `BackgroundTask` means "keep collecting quietly in the background".

   ```dart
   protocol.addTaskControl(
     ImmediateTrigger(),
     BackgroundTask(measures: [
       Measure(type: SensorSamplingPackage.STEP_EVENT),
       Measure(type: DeviceSamplingPackage.BATTERY_STATE),
       Measure(type: DeviceSamplingPackage.APP_LIFECYCLE_EVENT),
     ]),
     phone,
   );
   ```

4. **Start it.** This part is unchanged from your first app:

   ```dart
   final client = SmartPhoneClientManager();
   await client.configure();

   final study = await client.addStudyFromProtocol(protocol);
   await client.tryDeployment(study.studyDeploymentId, study.deviceRoleName);
   client.resume();
   ```

</Steps>

<Aside type="tip">
To switch between database and files, change only the endpoint in step 1. CAWS also
uses an endpoint (`CarpDataEndPoint`), but there the protocol is set up in the portal
and the app signs in. See [Use CAWS](/start/storage-caws/).
</Aside>

## Getting the data off the phone

The data lives in the app's private folder:

- **Database:** `carp-data`, in the app's `databases` folder.
- **Files:** `carp/deployments/<deployment id>/data/`, in the app's documents folder.

To copy it to your computer:

- **Android:** in Android Studio, open **Device Explorer** and go to
  `data/data/<your app id>/`. The database is in `databases/`, files in `app_flutter/carp/`.
- **iPhone:** add `UIFileSharingEnabled` = `YES` to `Info.plist`, plug the phone into
  a Mac, and open it in **Finder → Files**.

## When to move on

Local storage is perfect for trying things out. For a real study you usually
want data to arrive centrally without touching each phone. Then look at
[CAWS](/start/storage-caws/) or [your own server](/start/storage-own-server/).

More detail: [Data Managers](/carp-mobile-sensing/infrastructure/data-managers).
