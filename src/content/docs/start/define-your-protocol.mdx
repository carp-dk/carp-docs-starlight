Every CARP study starts with a **study protocol**. It answers four questions:

| Question | In the protocol | In this example |
| --- | --- | --- |
| **Where** is data collected? | Device | The phone |
| **What** is collected? | Measures | Steps and battery |
| **When** is it collected? | Trigger | Right away, all the time |
| **Where** does data go? | Data endpoint | A database on the phone |

A protocol is a JSON file, `protocol.json`. You can write it in Dart with CARP Mobile Sensing and save it as JSON, or edit the JSON directly.

<Tabs>
<TabItem label="Dart">

```dart
final protocol = SmartphoneStudyProtocol(
  name: 'My first study',
  dataEndPoint: SQLiteDataEndPoint(),
);

// The phone collects the data, the participant is the person using it.
final phone = Smartphone();
protocol.addPrimaryDevice(phone);
protocol.addParticipantRole(ParticipantRole('Participant'));

// Start right away and keep collecting in the background.
protocol.addTaskControl(
  ImmediateTrigger(),
  BackgroundTask(name: 'Steps and battery', measures: [
    Measure(type: SensorSamplingPackage.STEP_EVENT),
    Measure(type: DeviceSamplingPackage.BATTERY_STATE),
  ]),
  phone,
);

print(toJsonString(protocol)); // this is your protocol.json
```

</TabItem>

CAMS adds the `Monitoring Smartphone` task itself. It records errors and task events, and you don't need to touch it.

<Aside type="note">
`id` and `createdOn` are set when the protocol is created. If you copy a protocol, give it a new `id`. The CARP Portal fills these in for you when you upload it.
</Aside>

## Change what is collected

<Steps>

1. **Add a measure** to collect more. Every measure type, and the package that adds it, is in [Available packages](/carp-mobile-sensing/sampling-packages/available-packages/).
2. **Change the trigger** to collect at other times: every hour, at 8:00, or when a survey is due. See [Triggers](/carp-mobile-sensing/domain/triggers/).
3. **Add a task** the participant does, such as a survey or a short test. See [Tasks](/carp-mobile-sensing/domain/tasks/).

</Steps>

Everything a protocol can hold is in [Study protocol](/carp-mobile-sensing/domain/study-protocol/).

<Aside type="tip" title="The file stays the same">
The same `protocol.json` runs on your laptop, on a test server and in production. Only the server and sign-in change, never the protocol.
</Aside>
