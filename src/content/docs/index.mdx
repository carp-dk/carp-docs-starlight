## What is CARP?

<div class="carp-intro">
<div>

CARP (Copenhagen Research Platform) is a set of open-source tools for **collecting data from smartphones, wearables and the people who carry them**. Researchers use it for health and behavior studies. Developers use it to add sensing to any Flutter app.

* **Sensors:** location, steps, activity, sleep, screen, battery, Bluetooth and more
* **Wearables and health apps:** Health Connect, Apple Health, Apple Watch, Polar, Movesense
* **From people:** surveys, cognitive tests, voice, video and photos

See every measure in the [sampling packages table](/carp-mobile-sensing/sampling-packages/available-packages/#measure-types).

## Why CARP?

<CardGrid>
  <Card title="Open source" icon="github">
    MIT license. Read the code, change it, run it yourself.
  </Card>
  <Card title="Private by design" icon="approve-check">
    Participants can join anonymously with a code, and data can be anonymized before it leaves the phone. See [privacy](/carp-mobile-sensing/domain/data-endpoints-and-privacy/).
  </Card>
  <Card title="Integrations are ready" icon="puzzle">
    Phone sensors, Health Connect, Apple Health, Apple Watch, Polar, Movesense, Movisens and eSense. See [available packages](/carp-mobile-sensing/sampling-packages/available-packages/).
  </Card>
  <Card title="Add anything" icon="rocket">
    If a phone sensor or wearable has an SDK, you can add it as a [sampling package](/carp-mobile-sensing/sampling-packages/create-your-own/).
  </Card>
</CardGrid>
