## Measure types

CAMS comes with a large set of predefined measure types, each available in different sampling packages. Some measures are [part of CAMS](#built-in-sampling-packages), others are available in [separate sampling packages](#external-sampling-packages), and some are part of [device-specific sampling packages](#wearable-device-sampling-packages).

The tables below describe, for each measure:

* **Type Name** - all type names are of the format `dk.cachet.carp.<type>`, where `type` is listed below
* **Availability** on Android and/or iOS
* The **sampling package** containing the measure
* A **description**

<Aside>
Measures marked with * are one-time measures.
</Aside>

### Wearable device sampling packages

Type         | Android/iOS | Package |Description |
-------------|:-------:|:-----------:|:------------ |
`health` | **+ +** | [`health`](https://pub.dev/packages/carp_health_package) | Collects different types of health data from [Apple Health](https://www.apple.com/health/) and [Google Health Connect](https://health.google/products/) that may come from connected wearable devices |
`movisens`   | **+ -** | [`movisens`](https://pub.dev/packages/carp_movisens_package) | Activity and Heart Rate Monitoring using the [Movisens](https://www.movisens.com/en/) [Move4](https://www.movisens.com/en/products/activity-sensor/) and [EcgMove4](https://www.movisens.com/en/products/ecg-sensor/) devices |
`esense` | **+ +** | [`esense`](https://pub.dev/packages/carp_esense_package) | Inertial measurement unit (IMU) sensor events and button press/release events from the [eSense](http://www.esense.io) device |
`polar` | **+ +** | [`polar`](https://pub.dev/packages/carp_polar_package) | Inertial measurement (accelerometer, gyroscope, magnetometer) and heart rate (ECG, PPI, PPG, HR) data from the [Polar](http://www.polar.com) devices |
`movesense` | **+ +** | [`movesense`](https://pub.dev/packages/carp_movesense_package) | State (tap), heart rate (HR), ECG, and Inertial Movement Unit (IMU - accelerometer, gyroscope, magnetometer) data from the [Movesense](http://www.movesense.com) devices |
`watch.aware` | **- +** | [`aware`](https://pub.dev/packages/carp_aware_package) | Motion, heart rate, battery, location, heading, Bluetooth, ambient noise, and sound classification collected on an [Apple Watch](https://www.apple.com/watch/) using the [AWARE](https://github.com/awareframework/com.awareframework.ios.sensor.applewatch) watchOS framework. Note that these measures use the `dk.carp.watch.aware` namespace - see the [Apple Watch Sensing](/packages/apple-watch/) documentation |

<Aside>
Each of these device measures has sub-types, such as `dk.cachet.carp.movisens.hr` for heart rate (HR) measures from the Movisens device.
</Aside>
