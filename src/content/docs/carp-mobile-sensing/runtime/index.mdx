`lib/runtime/` **runs** what `lib/domain/` describes. You talk to one class, [`SmartPhoneClientManager`](https://pub.dev/documentation/carp_mobile_sensing/latest/runtime/SmartPhoneClientManager-class.html); everything below it is created for you.

```text
SmartPhoneClientManager            one per app
└─ SmartphoneStudyController       one per study
   └─ SmartphoneDeploymentExecutor
      └─ TaskControlExecutor       one per trigger + task pair
         ├─ TriggerExecutor        decides when
         └─ TaskExecutor           decides what
            └─ Probe               one per measure, reads the sensor
```

Every level is an `Executor` with the same lifecycle: `initialize`, `resume`, `pause`, `dispose`. Resuming the client resumes the whole tree.
