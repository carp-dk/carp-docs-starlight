`lib/infrastructure/` holds the concrete implementations of the interfaces declared in `lib/domain/services/`, plus the built-in sampling packages. Replace any of them to change how CAMS stores, deploys or notifies.

## Where in the repo

| File | What is in it |
| --- | --- |
| [`infrastructure/data_managers/`](https://github.com/carp-dk/carp.sensing-flutter/blob/main/carp_mobile_sensing/lib/infrastructure/data_managers/) | Console, file and SQLite data managers |
| [`infrastructure/services/`](https://github.com/carp-dk/carp.sensing-flutter/blob/main/carp_mobile_sensing/lib/infrastructure/services/) | Deployment, persistence, notifications, background, logging |
| [`infrastructure/settings.dart`](https://github.com/carp-dk/carp.sensing-flutter/blob/main/carp_mobile_sensing/lib/infrastructure/settings.dart) | `Settings`: paths, user id, debug level |
| [`infrastructure/sampling_packages/`](https://github.com/carp-dk/carp.sensing-flutter/blob/main/carp_mobile_sensing/lib/infrastructure/sampling_packages/) | The built-in sampling packages, see [Sampling packages](/carp-mobile-sensing/sampling-packages/how-they-work) |
