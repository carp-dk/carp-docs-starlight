`Settings` is a singleton initialised by `SmartPhoneClientManager().configure()`. It holds the app name and version, the time zone, a persistent random user id, and the base paths for deployments, cache and data files.

Set `Settings().debugLevel` (`none`, `info`, `warning`, `debug`; default `warning`) to control what CAMS prints. `debug` output only appears in Flutter debug mode.
