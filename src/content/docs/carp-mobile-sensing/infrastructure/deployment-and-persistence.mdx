Three services make CAMS run offline and keep its state:

- [`SmartphoneDeploymentService`](https://pub.dev/documentation/carp_mobile_sensing/latest/infrastructure/SmartphoneDeploymentService-class.html) is an in-memory `DeploymentService` that deploys a protocol on this phone. Use a remote one (e.g. CAWS) to deploy from a server.
- `PersistenceService` keeps studies (table `studies`) and the user task queue (table `task_queue`) in SQLite, so they are restored after an app restart.
- [`FileStudyProtocolManager`](https://pub.dev/documentation/carp_mobile_sensing/latest/infrastructure/FileStudyProtocolManager-class.html) reads and writes protocol JSON files, implementing the `StudyProtocolManager` interface.
