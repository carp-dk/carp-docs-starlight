You don't change the app. You give it four things, and the app builds everything the participant sees from them:

| You provide | What it controls |
| --- | --- |
| **Study protocol** (`protocol.json`) | What is collected, when, and which tasks appear in Tasks. See [Study protocol](/carp-mobile-sensing/domain/study-protocol/). |
| **Informed consent** (`consent.json`) | The consent text and the signature step. |
| **Translations** | The texts, per language. |
| **Messages** | The messages on the Home tab. |

The protocol is the same object you build with CAMS, serialized to JSON. See [JSON serialization](/carp-mobile-sensing/domain/json-serialization/).

## Two modes

| | CAWS | Local |
| --- | --- | --- |
| **Use it for** | Real studies | Designing and debugging a protocol, consent and translations |
| **Where the study lives** | On CARP's server. The app signs in and downloads protocol, consent, translations and messages. | In the app's `assets/carp/` folder |
| **Joining** | QR code, short code, or email invitation. See [Use CAWS](/start/storage-caws/). | None, the study is built in |
| **Data goes to** | CAWS | A SQLite database on the phone |

For a real study, you upload the four things to CAWS before participants join. To get access, see [Getting access](/start/storage-caws/#getting-access).

## Test a protocol locally

You need Flutter and the app's source code, since local mode loads files from the app's assets.

```bash
git clone https://github.com/carp-dk/carp_study_app
cd carp_study_app
flutter run --dart-define="deployment-mode=local" --dart-define="debug-level=debug"
```

Put your files under `assets/carp/`:

| File | Folder |
| --- | --- |
| `protocol.json`, `consent.json` | `assets/carp/resources/` |
| Language files | `assets/carp/lang/` |
| Message files | `assets/carp/messages/` |

<Aside type="caution">
The app keeps the protocol on the phone. When you change it, **delete the app and its data** before you run it again.
</Aside>

`deployment-mode` can also be `dev`, `test` or `production`. These use CAWS. The default is `production`.
