# CARP Documentation

Technical documentation for the [Copenhagen Research Platform (CARP)](https://carp.dk), built with [Starlight](https://starlight.astro.build) (Astro).

Content was migrated from [carp-docs-mintlify](https://github.com/carp-dk/carp-docs-mintlify).

## Develop

```sh
npm install
npm run dev        # http://localhost:4321
```

## Build

```sh
npm run build      # static HTML in ./dist
npm run preview    # serve ./dist locally
```

`dist/` is plain static files. Point any web server at it, e.g. nginx with [`nginx.conf`](nginx.conf):

```sh
docker build -t carp-docs .
docker run -p 8080:80 carp-docs   # http://localhost:8080
```

## Structure

```
src/content/docs/
├── architecture.mdx          # CARP architecture overview (Mermaid)
├── api-reference.mdx         # links to Dart API docs on pub.dev
├── carp-mobile-sensing/      # CAMS framework docs
└── packages/                 # health, debug-toolkit, apple-watch
public/                       # images, favicon (served as-is)
astro.config.mjs              # site config + sidebar
src/styles/carp.css           # CARP brand colours
```

- Add a page: create an `.md`/`.mdx` file under `src/content/docs/` and add its slug to `sidebar` in `astro.config.mjs`.
- Diagrams: use a ` ```mermaid ` code block.
- Components: [Starlight components](https://starlight.astro.build/components/using-components/) (`Aside`, `Tabs`, `Steps`, `Card`, `LinkCard`, …).
- Dart API reference lives on pub.dev (generated by `dart doc`); link to `https://pub.dev/documentation/<package>/latest/`.
